Mitgliederliste Dienst

Mitglieder verwalten

CSV-Import: Eine Zeile pro Mitglied, beispielsweise Max Mustermann oder 104;Max Mustermann. Auch Tabellen mit Spalten wie „Mitgliedsnummer;Vorname;Nachname“ werden erkannt. Bereits vorhandene Namen werden übersprungen.

Datenschutz & Speicherung: Die Daten werden ausschließlich lokal im Browser (localStorage) gespeichert und nicht an einen Server gesendet. Andere Geräte sehen Änderungen nicht. Löschen von Browserdaten oder die Nutzung des privaten Modus kann Daten entfernen. Deshalb regelmäßig Excel-Dateien sichern. Für eine zuverlässige Nutzung auf dem iPhone die Datei über eine HTTPS-Website (z. B. GitHub Pages) in Safari öffnen. Beim direkten Öffnen aus der Dateien-App kann die Speicherung eingeschränkt sein. Die App benötigt nach dem Laden keine Internetverbindung.
